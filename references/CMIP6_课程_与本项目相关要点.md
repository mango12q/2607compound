# CMIP6 数据介绍与应用 — 与本项目复现最相关的要点

> 来源：`1-CMIP6数据介绍与应用-1(1).pdf`（14 页）
> 与本项目（Compound coastal marine-terrestrial heatwaves in Europe）的关联已按 **直接可用 / 参考理解 / 背景了解** 三级标注。

---

## 一、直接可用（项目实现中可能用到）

### 1. CESM 在 CMIP 谱系中的位置
- 课件第 4 页列出 **CESM2 / CESM2-FV2 / CESM2-WACCM** 等 CMIP6 模式。
- **本项目注意**：论文归因部分使用的是 **CESM1-LE（CMIP5 时代，约 20 成员）**，不是 CMIP6。
- 但课件有助于理解：CESM 系列的演化脉络、不同分辨率/配置（FV2、WACCM）对区域模拟的影响。
- **实操建议**：下载/处理 CESM1-LE 数据时，可参考课件中关于“GCM 日尺度/月尺度变量列表”的表格结构，确认你需要的 TREFHT、PRECC、PRECL 等变量在对应实验（ALL / FixGHG）中的可用性。

### 2. 统计降尺度与偏差订正（第 9-14 页）
- **核心方法**：建立 GCM 与观测之间的映射关系，假设该关系“不随时间变化、周期性重复”。
- **常见手段**：多元回归、偏差订正（Bias Correction）、随机天气发生器。
- **与本项目的关联**：
  - 若你的研究需要将 **ERA5 / CESM** 降尺度到与 E-OBS/OISST 一致的更高分辨率网格，偏差订正是最可行的一步。
  - 课件中的“多元回归”思路可映射到 Python 的 scikit-learn 或 xarray 重采样后的空间匹配。

### 3. 格点化观测参考（第 11-12 页）
- 列出 PRISM、DAYMET、MT-CLIM 等格点化数据集。
- **对本项目的意义**：
  - 你已有 **OISST（海洋）** 和 **E-OBS（陆地）**，课件提供的是“其他常见格点观测”的横向对比。
  - 若后续需要补充陆面验证数据集，可参考这些格点产品的空间分辨率和时间覆盖。

## 二、参考理解（帮助定位数据与流程）

### 1. CMIP6 子比较计划（第 7-8 页）
- CMIP6 下分多个子计划（如 ScenarioMIP、DAMIP、GMMIP 等）。
- **对本项目的意义**：
  - 虽然你处理的是 CESM1-LE（CMIP5），但理解“历史实验 / 强迫实验 / 归因实验”的分类逻辑，有助于在数据下载时快速定位 historical、all forcings、fixed GHG 等实验名称。
  - 课件中提到的“周天军, 2019”文献，可作为查阅 CMIP6 实验设计的参考文献。

### 2. 动力降尺度（WRF / RegCM）（第 9-10 页）
- 课件提到了动力降尺度工具（WRF、RegCM）。
- **对本项目的意义**：
  - 如果你的研究最终需要 **更高分辨率的欧洲区域模拟**（例如验证特定沿海站点），动力降尺度是可选路线。
  - 但鉴于当前数据量已约 430 GB，建议优先完成 **统计降尺度/偏差订正** 的观测流程验证（P0/P1），再考虑 WRF。

## 三、背景了解（扩展知识）

### 1. CMIP 历史与目的
- CMIP 起源于 AMIP（1989-1994），1995 年由 WCRP 发起。
- 目的：推动模式发展、增进对地球气候系统的科学理解。
- **对本项目的意义**：理解为什么 CESM1-LE 有 40 个成员、为什么需要做 bootstrap 归因——正是因为 CMIP 框架下“多模式/多成员集合”的设计哲学。

### 2. 常见 GCM 列表（第 5-6 页）
- 课件列出了大量 CMIP6 模式及其日尺度/月尺度覆盖情况。
- **对本项目的意义**：可作为扩展分析时的参考（例如，若需要对比多个模式对欧洲 compound heatwave 的模拟能力）。

## 四、对本项目下一步的建议

| 优先级 | 建议 |
|--------|------|
| **P0** | 先完成 OISST + E-OBS + ERA5 的观测流程验证，不依赖 CMIP6 课件。 |
| **P1** | 若需处理 CESM1-LE 数据，参考课件中的“偏差订正”思路，编写 Python 预处理模块。 |
| **P2** | 若论文方法部分需要引用 CMIP 框架/降尺度方法，可将课件第 3、9-14 页作为背景材料。 |
| **暂不做** | 不建议为了复现而额外运行 WRF 动力降尺度，除非观测流程已稳定且区域分辨率不足。 |
