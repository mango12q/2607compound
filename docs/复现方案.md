## 二、核心实验原理

### 1. 热浪定义

- **阈值**: 1983–2012 年气候学分布的 **90 百分位**
- **持续时间**: 连续 ≥ 5 天（允许 < 2 天的中断）
- 陆地和海洋使用**统一标准**以保证时间一致性

### 2. 复合热浪定义

- **复合海洋-陆地热浪 (MHW–THW)**: 配对的沿海陆地和相邻海洋格点中，T2m 和 SST **同时**超过各自阈值
- **关键条件**: 论文存在两种口径——Methods L477 "simultaneously exceed"（共超标）与
  L520 "fully encompasses"（MHW 事件完全涵盖 THW）。复现采用 **方案 B**：
  图1a–i / 图1m / 图2 用共超标口径，图1j–l 用 MHW 包络口径
  （依据与实证见 `results/复现报告.md` §5 与 `results/图1_图2_共超标定义_修订报告.md`）
- **独立陆地热浪**: 相邻海洋格点中**无并发**海洋热浪的陆地热浪

### 3. 沿海格点对识别

- 基于海洋 (SST) 和大气 (T2m) 格点构建陆地-海洋邻接掩码
- 沿海大气格点使用 **4-连通邻域方法**识别
- 结果限于 E-OBS 陆地温度数据可用的区域

### 4. 核心指标

- **复合热浪比 (CHR)**: 复合热浪天数 / 独立陆地热浪天数
  - CHR > 1: 并发海洋热浪延长陆地热浪
  - 2023 年峰值 CHR = 3.5
- **共现概率**: 复合天数 / 陆地热浪天数

### 5. 归因分析 (FAR/PR)

使用 **CESM1-LE** 大型集合（分析期 2000–2021，20 成员 × 22 年 = 440 模型年/组）：

- **ALL 强迫**: 20 成员，包含所有人为+自然强迫
- **FixGHG**: 20 成员，温室气体浓度固定于 1920 水平（CESM1-LE **XGHG** 实验；
  已实证 co2vmr 恒定，见 `results/复现报告.md` §11.2）
- **统计单元（论文口径）**: 每成员每年的**区域聚合暴露时间**（地中海&黑海 / 欧洲全岸
  复合天数）池化为 440 模型年；概率 = 暴露 ≥ 阈值的模型年占比
- **FAR (可归因风险比例)**: FAR = 1 − P_FixGHG/P_ALL（论文 Eq.2）
- **PR (概率比)**: PR = P_ALL/P_FixGHG（论文 Eq.3）
- **不确定性**: 1000 次非参数自助法 (bootstrap)；图 3 FAR/PR 取 5–95% CI
- **重现期（图 4a–c）**: GEV（MLE）+ 1000 bootstrap，5/10/20/50/100 年重现水平，
  中位数 + 2.5–97.5% CI，覆盖海洋/陆地/复合三类事件（地中海&黑海）

### 6. 湿热分析

- **湿球温度 (WBT)**: 从 ERA5 的 Tmax、露点温度、地表气压计算
- **阈值**: WBT ≥ 25.5°C（基于 ISO 7243 标准）
- **比湿 (SH)**: SH ≥ 19 g/kg
- **分析范围**: 地中海海岸线向内 100 km 的陆地格点

## 四、复现步骤规划

### Phase 1: 数据准备

1. 下载 OISST v2.1 日度 SST (1982–2023)
2. 下载 E-OBS 日度 T2m (**1983**–2023；气候态 1983–2012 需要 1983 年数据)
3. 下载 ERA5 日度 Tmax、露点温度、地表气压 (1984–2023)
   - ⚠️ 地表气压需 **0.25°** 版本（论文口径）；现有全球件为 1.0°，0.25° 欧洲框见 DATA_REQUIREMENTS 数据集 3b+
4. 下载 OAFlux 蒸发数据 (1991–2020)
5. 下载 CESM1-LE 数据：
   - ALL 强迫: 20 成员 daily T2m + SST
   - XGHG（= 论文 FixGHG）: 20 成员 daily T2m + SST

### Phase 2: 热浪检测

6. 计算 1983–2012 气候学 90 百分位阈值（陆地和海洋分别计算）
7. 运行 R `heatwaveR` 检测海洋热浪（`python/detect_events.R`；早期 Python marineHeatWaves 方案已弃用备份）
8. 运行 `heatwaveR` 检测陆地热浪
9. 应用 5 天持续时间阈值 + 2 天中断容限

### Phase 3: 沿海格点配对与复合事件识别

10. 构建陆地-海洋邻接掩码（4-连通邻域）
11. 识别配对的沿海格点对
12. 检测复合热浪：陆地热浪被海洋热浪完全涵盖
13. 计算独立陆地热浪天数

### Phase 4: 观测分析

## 五、关键注意事项

1. **格点配对细节**: 已按原文 Methods 实现（4-连通邻域 + 最近海洋格点一配一，`MAX_GRID_DIST_DEG=0.5`，沿海对 1434 个）
2. **FAR/PR 公式**: 需参考 Hannart et al. (2016) 原文 (QJRMS 142, 106–114)
3. **WBT 计算**: 论文 Methods 确认为由 Tmax + 露点温度 + 地表气压估算日最高 WBT；SPEC 3.8 提供 Stull/迭代双实现，具体公式经锚点验证后定稿
4. **CESM1-LE 数据量**: 20 成员 × 2 情景 × ~165 年，数据量巨大 (~TB 级)，需在超算或高性能集群上处理
5. **计算资源**: 真正的瓶颈是 **40 个 CESM 模拟的逐格点热浪检测**（P0 实测 27 s/成员）；
   归因 bootstrap 本身很轻（样本是池化后的 440 个模型年标量，秒级到分钟级）
6. **模型侧检测基准期**: 论文未明示；观测用的 1983–2012 对 2000–2021 的模型不适用。
   当前 P0 采用 XGHG 集合合并反事实基准，正式版需 leave-one-out（见 `TECHNICAL_SPEC_PHASE_B.md` 步骤 2b）
