## 二、实质性不一致 / 缺失（P0，建议修正规划后再进入 Phase 5/6 全量）

### P0-1 规格文档 FAR 公式写反
- 论文 Eq.2：`FAR = 1 − P_FixGHG / P_ALL`。
- `TECHNICAL_SPEC.md` §3.9 `calc_FAR` 与 `TECHNICAL_SPEC_PHASE_B.md` 步骤4 均写成 `FAR = 1 − P_factual / P_counterfactual`（方向相反；照实现会得到负 FAR）。
- 实际 `python/phase6_cesm.py` L612 `far = 1 - 1/PR` 是正确的 → **只需改文档**。

### P0-2 重现期分析与论文方法不符（图4）
- 论文 Methods "Return level and period estimation using GEV"：对 FixGHG 年暴露序列做 **1000 次 bootstrap + GEV（MLE）拟合**，给出 5/10/20/50/100 年重现水平的**中位数 + 2.5/97.5% CI**；再把 FixGHG 重现水平映射到 ALL 的等效重现期，并对 ALL 重复 bootstrap 估计不确定性。
- 规划现状：`TECHNICAL_SPEC.md` **完全没有 GEV 模块**；`PHASE_B` 步骤5 只有 `RP = 1/概率` 的经验重现期，且只算了**复合**事件一类。
- 论文图4 需要 **a 沿海海洋热浪、b 沿海陆地热浪、c 复合** 三条重现期曲线（地中海&黑海）；规划未覆盖 a、b。
- 另外：图4 误差棒是 **2.5–97.5% CI**（95%），与图3 的 5–95% 不同——任何规划文件都未写明这一区分（config 里只有一个全局 CI_ALPHA）。

### P0-3 归因概率的统计单元与论文不同
- 论文：把每个成员每年的**区域聚合暴露时间**（地中海&黑海 / 欧洲全岸的复合天数）作为样本，440 模型年中"暴露 ≥ 阈值"的比例即 P。
- `TECHNICAL_SPEC.md` §3.9 `calc_probability`：逐**格点**年超标占比（把格点-年当样本）——统计单元不一致。
- 实际 P0（phase6_cesm.py）已按区域聚合（med_mean/med_max），方向正确；但正式版规划文本应改为论文口径（复现报告 §5.1#8 也已把"区域日数聚合"列为正式版要求）。

### P0-4 ERA5 地表气压为 1.0°，论文口径 0.25°
- 论文 Methods：Tmin/Tmax、q、WBT 所需变量均"derived from ERA5 … 0.25°"。
- 实际：`ERA5/sp` 为 **1.0° 日值**（d2m/tmax 0.25°）。WBT/SH 将在 1.0° 气压场上混合 0.25° 温露场。
- DATA_REQUIREMENTS 已标注"需重采样对齐"，但把 1.0° 插值到 0.25° 不产生新信息；**建议补一个 0.25° sp 的欧洲框下载任务**（几十 GB 量级）或在方法偏离清单中明确降级理由。

### P0-5 PHASE A 的图1面板定义与论文不符
- `TECHNICAL_SPEC_PHASE_A.md` MATLAB 注释：
  - 图1a–i 年份写为 **1985, 1990, 1995, 2000, 2003, 2010, 2015, 2018, 2022**；
  - 图1j–l 写为"地中海平均复合天数、独立天数、CHR"。
- 论文：图1a–i 年份为 **2003, 2006, 2010, 2012, 2018, 2019, 2020, 2022, 2023**；图1j–l 是 **地中海（含黑海）、波罗的海沿岸、全欧海岸** 三个区域的**复合天数**时间序列（1983–2023）。
- （实际出图代码 figures.py 未沿用此错误，但规划文本需要更正，避免回归。）

### P0-6 PHASE C 的验证锚点与论文相反/偏低
- "蒸发趋势符号：负趋势（地中海水域）"——论文明确说蒸发**增强**（"ocean evaporation has intensified, localized increases exceeding 10 cm yr⁻¹ decade⁻¹ during JAS"，图5b 为正趋势）。按该锚点会把正确的正趋势判为失败。
- "SST 趋势 ~0.2–0.3 °C/decade ±0.1"——论文锚点是"**up to 0.5 °C/decade**"（1994–2023 JAS）。
- 其余锚点（2023 WBT≥25.5 ≈ 40 天）正确。
