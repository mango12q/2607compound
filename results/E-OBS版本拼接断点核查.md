# E-OBS v33.0e / v29.0e 拼接断点核查（2010/2011）— 2026-09-23

> 动机：`data/E-OBS/EOBS_tg_1983_2023.nc` 由三段合并，其中 **2011-01-01 起版本从
> v33.0e 变为 v29.0e**。E-OBS 不同版本使用的站点网不同，版本切换可能在序列上引入
> **非气候的台阶**；而论文的核心结论（2003 后加速增暖/复合热浪上升）恰依赖该时段。
> 这项风险此前**从未量化过**。
>
> **结论：未发现拼接伪影。** 四项独立检验一致给出阴性。
> 复算脚本：`results/eobs_splice_check.py`；原始输出：`logs/eobs_splice.txt`。

## 一、拼接点核对（T1）

| 分段 | 版本 | 实际覆盖 | 天数 |
|---|---|---|---|
| seg1 | v33.0e | 1980-01-01 – 1994-12-31 | 5479 |
| seg2 | v33.0e | 1995-01-01 – 2010-12-31 | 5844 |
| seg3 | **v29.0e** | **2011-01-01** – 2023-12-31 | 4748 |

**seg2 与 seg3 无重叠期**（2010-12-31 / 2011-01-01 严丝合缝）→
**无法对同一时段做直接的版本对照**，只能做统计检验。这正是本核查的必要性所在。

---

## 二、台阶检验 + 安慰剂（T2，主检验）

对地中海&黑海区域年均 `tg` 序列，在**每一个**候选断点年 b（1988–2018，共 31 个）
拟合同一个模型，看 2011 是否异常：

```
anomaly  ~  a + c·t  [+ q·t²]  + d·1[t ≥ b]
```

| 趋势设定 | 2011 的台阶 | t 值 | 在 31 个候选年中的 |t| 排名 |
|---|---|---|---|
| 仅线性 | −0.206 °C | −0.97 | 第 **9** / 31 |
| 线性 + 二次 | −0.190 °C | −0.67 | 第 **16** / 31 |

**|t| 最大的候选年是 1998（+0.448 °C, t=2.12）与 1994（+0.388 °C, t=1.95）**，
即真实的强厄尔尼诺/皮纳图博火山后年份——**不是拼接年**。

> 判读：2011 在所有可能的断点年里**处于中位**，t 值远未达显著
> （|t| < 1，而 31 个候选里最大的也只有 2.1）。若存在版本伪影，
> 2011 应当是显著的离群点。

## 三、平滑度检验（T3）

物理依据：站点网变稀疏 → 空间插值更强 → 场更**平滑** → 相邻格点差分变小。

| 时段 | 空间粗糙度（相邻**且都有效**格点对的平均绝对差，地中海&黑海） |
|---|---|
| 2001–2010 | 均值 0.8618 / 中位 0.8565 |
| 2011–2020 | 均值 **0.8672** / 中位 0.8639 |
| 相对变化 | **+0.62%**（无平滑化，反而略增） |

粗糙度序列在 2011 的台阶：**−0.0103（t = −0.86）**，不显著。

逐年值（2005–2016）：`0.8802 / 0.8417 / 0.8578 / 0.8781 / 0.8616 / 0.8340 /
**0.8639**(2011) / 0.8897 / 0.8741 / 0.8421 / 0.8512 / 0.8471`
→ **2011 完全落在邻近年份的正常波动区间内**，无突变。

## 四、季节与分区一致性（T4）

判据：站点网变更会**同时**作用于所有季节与所有区域，留下**同号、同量级**的台阶；
真实气候信号的季节/区域结构不会如此。

**分季节（地中海&黑海，含二次趋势）：**

| 季 | 台阶 | t |
|---|---|---|
| DJF | −0.726 °C | −1.34 |
| MAM | **+0.444** °C | +0.76 |
| JJA | −0.027 °C | −0.08 |
| SON | −0.446 °C | −0.92 |
| JAS | **+0.219** °C | +0.54 |

→ **符号正负交替**（DJF 与 JJA 反号），无一显著。与"站点网变更"预期的同号台阶不符。

**分区域（JJA，含二次趋势）：**

| 区域 | 台阶 | t |
|---|---|---|
| 地中海&黑海 | −0.027 °C | −0.08 |
| 西地中海 | −0.399 °C | −0.76 |
| 中地中海 | **+0.088** °C | +0.16 |
| 东地中海 | −0.287 °C | −0.68 |
| 波罗的海 | −0.564 °C | −0.91 |
| 大西洋岸 | −0.357 °C | −0.80 |

→ 中地中海反号，其余量级小且均不显著。

## 五、结论与留档

**四项检验一致：未发现 2010/2011 版本切换引入的伪影。**

- 台阶幅度小（−0.2 °C 量级）且**不显著**（|t| < 1）
- 在全部 31 个候选断点年中**排名中位**（第 9 / 16），远非离群
- 空间平滑度**无变化**（+0.62%，且 2011 值落在邻近年份正常区间）
- 季节与区域上**符号不一致**，不符合"站点网变更"的特征

**因此：E-OBS 版本混用对图1/图2 的结论不构成已证伪的风险。**

### 仍需在文档中保留的偏差说明

版本混用本身仍是**与论文的差异**（论文未注明 E-OBS 版本），应继续留在
`复现报告.md` §5.1 的偏差表里，但**理由可从"可能影响峰值年"下调为"已做四项检验、
未发现伪影"**。若日后有条件，统一到单一最新版本重跑仍是最干净的收尾方式。
