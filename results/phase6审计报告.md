## 1. 逐维度回答任务书 5 项

### 1.1 网格与配对

**POP（海洋 ~1°）→ f09 大气网格的湿点映射（KMT 用法）—— 正确，但有两处健壮性缺口。**

- KMT>0 判湿点 → 按 `argmin` 映射到 f09 格、容差 0.75 格距：实测全球 POP 湿点 86,212、欧洲框内 2,770、通过容差 2,986（>框内数，因容差窗口重叠 1.50×，argmin 取最近者，符合"窗口重叠"预期），唯一 f09 海格 1,231。**206 对可逐行复现**。
- 缺口 ①：f09 实测格距是 **0.9424° lat × 1.2500° lon**（= 180/191），代码注释写 "~1°" 不准确；`MAX_PAIR_DIST_DEG=1.0` 在 cos 加权空间里 ≈ **112.2 km**，而观测侧 0.5 单位 ≈ 55.6 km ⇒ **模型侧允许的陆–海分离约为观测侧的 2.1 倍**（206 对大圆距 median 81.6 / max 134.1 km）。
- 缺口 ②：24 个 f09 海格点仅由**欧洲框外**的 POP 湿点经 argmin 夹到 lon=−16.25 边界列而判为海；海陆掩码**完全来自 POP KMT，未与 CAM landmask 交叉核对**（误差未判定）。

**为何是 206 对、上限 1.0°，与观测 2039 对/1434 海点（0.5°）的口径差异是否被如实记录。**

- 206 对 = f09 欧洲框 49×51 上的 357 个 4-连通海岸陆点中，与 POP 湿点距离 ≤1.0 单位者（`binary_erosion` 4-连通腐蚀取边缘 = 论文 L512-514 的 4-邻域移位法，语义等价）。
- **口径差异只在 `results/复现报告.md:338,344,347` 登记**；`AGENTS.md:81`、`TECHNICAL_SPEC.md:214/787/790`、`TECHNICAL_SPEC_PHASE_A.md:17/18/150/151/295`、`docs/复现方案.md:155` **只有观测侧 0.5°/2039/1434，完全没写模型侧 206/1.0°**。⇒ **记录不完整**，应在 `AGENTS.md` 与 SPEC 中补登。

### 1.2 检测语义

**结论：模型侧与观测侧 `detect_events.R` 语义并**不一致**，三处不同。**

| 环节 | 观测侧（R heatwaveR 0.5.5） | 模型侧（`phase6_cesm.py`） | 判定 |
|---|---|---|---|
| 阈值分位窗 | `windowHalfWidth=5`（11 天窗内**合并原始样本**求分位） | v1 MHW：单日 doy 分位；v2 SST：单日 doy 分位；v2 T2m：**axis 崩溃** | ✗ |
| `smoothPercentile` | `FALSE`（项目口径） | 不适用（Python 侧） | — |
| 事件游程 | 先取 ≥5 天游程作种子，再桥接 ≤2 天空档 | **先桥接再按总跨度 ≥5 过滤** | ✗ |
| 桥接头尾 | 吸尾部空档、不吸首部空档 | 无此概念 | ✗ |

- `smoothPercentile=FALSE` **仍然做 11 天窗合并**（源码取证 + 合成实测：`windowHalfWidth=5` vs `0` 的阈值差 mean 0.165 °C、max 1.058 °C）；`config.MHW_EVENTS_CSV` 指向的观测 MHW 确实走 11 天窗链路。
- 严格大于 / 时长含空档 / 跨年不切分 / NA 处理：**确认无误**。
- `detect_events.R` 的 `min_valid=730` 在 Python 路径缺失：**无影响**（模型域 206 点有效日 ≥8,029 > 730）。

### 1.3 阈值基准期

- **XGHG 集合合并基准含被检测成员自身（in-sample）—— 精确表述**：对 **XGHG 组成员**，阈值池含自身（in-sample）；对 **ALL 组成员**，阈值来自 XGHG 池、不含自身（out-of-sample）。所以"in-sample 污染"**只作用于 XGHG 一组**（归因的分母）。
- **主口径应为 leave-one-out —— 代码不支持**（`exclude_member` / `loo` 全项目 0 处），与 `TECHNICAL_SPEC_PHASE_B` 步骤 2b 已定口径不符。
- **偏差有多大**（3 成员实测）：
  - 阈值层：SST |Δ| 均 0.070–0.116 °C，T2m |Δ| 均 0.243–0.247 °C，**无系统方向**。
  - 检测层：LOO 使 XGHG 复合暴露 **+4.2% / +11.0% / +29.1%**（001/002/003）。
  - **注意必须与"阈值本身错了"分开陈述**：3 成员下 LOO 后池只剩 2 个，"池变小带来的抽样噪声"在 ALL 侧只贡献 −0.3%，但成员间离散很大（−24%~+9.4%），**3 成员实验会高估 LOO 的影响；20 成员时（19 vs 20）会小得多**。
- 论文**确实未给模型侧基准期**（唯一阈值句 `paper_text.txt:490/497` 指 1983-2012；Model data 节 `:621-631` 无阈值）。但 `:544-545`「同一套检测方法一致用于观测与模式」+ 模式覆盖 1920-2100 ⇒ 用 1983-2012 建模式基准期**技术上可行**；现行"同时段 XGHG 池"是自洽但**必须声明的偏离**（未判定孰优）。

### 1.4 复合与统计

- **复合确实复用 `identify_compound_events`**（共超标口径）—— 见上，6/6 逐值一致。
- **统计单元**：`_annual_per_pair` 输出 `med_mean / med_max / eur_mean / eur_max`，`cmd_attrib` 只用 med_mean 与 med_max；样本 = 成员 × 年 = 66（20 成员时 440）⇒ **结构上满足"区域年暴露时间池化 440 模型年"，但用哪一列（区域均值还是格点极值）未定**，而论文 Table 1/Fig.3c 的阈值 62/78/72 更接近区域暴露口径 ⇒ **现状引用 med_max 属口径错配**。
- **FAR / PR / CI**：公式正确；1000 次 bootstrap 与 5–95% 分位正确（`CI_ALPHA=(0.05,0.95)`）。
- **但 bootstrap 有两处问题**：① `inf` 被静默丢弃（见 P1-3）；② ALL 与 XGHG **独立重采样**符合论文 `:585-587` 的字面描述，但忽略同成员 22 年的自相关 —— 成员 block [19.5,54.0] / 成员内分层 [15.6,53.0] / 5 年移动块 [16.7,54.0] vs 现状 [14.67,53.0]，3 成员下差异不大，**20 成员建议改分层 + 块**。

## 3. 结论确定性分级

**【已确证】**（有可复算数字与独立互证）
P0-1 ~ P0-5、P1-1 ~ P1-5、P2-1 ~ P2-7；以及 §0「已确认无误」全部条目。其中 P0-1 由 Lead 与 detection-auditor、grid-auditor、baseline-stats-auditor **四方独立复现**（互相数字一致到 ±1%）；P0-2 由 Lead（450 例）与 detection-auditor（1,350 例、9 组参数）**独立复现**，两者均与真实 `heatwaveR::proto_event` 0 例不一致。

**【已否证】**（原被怀疑、经实测排除）
- ~~"POP nday1 SST 时间标签比 CAM TREFHT 晚 1 天"~~：原始 CAM 自带 `date` 变量，实测 `date[i]` = `time_bnds[i]` 的**右端**（i=1: date=19200102，bnds=[1920-01-01, 1920-01-02]）；原始 POP 的 `time_bound` 同样是**右端**（label 1920-01-03 ↔ [1920-01-02 01:00, 1920-01-03]）。**两者同约定，无相对滞后**。（baseline-stats-auditor 已据此撤回其 C11；误判根因是 CAM 的边界变量名是 `time_bnds` 而检索只找 `time_bound`，于是把"文件名起始日"当成了 CAM 的标签。）
  - 注：grid-auditor 的 E-1 仍以"POP 文件名 20051231 vs 标签 2006-01-01"主张 POP 偏 1 天。**该证据链缺 CAM 侧对应检查**：CAM 的文件名 `19200101-20051231` 与其**标签**一致，而 POP 的文件名 `19200102-20051231` 与其**物理日**一致 —— 两个产品的命名习惯不同，不能用来推断记录约定；决定性的 `time_bnds`/`date` 证据显示两者同为右端。**本报告采纳"无相对滞后"**，并把 grid-auditor 观察到的暴露变化（v1/v2 各 +7~10%）登记为**纯敏感性**，不作缺陷。

**【未判定】**
- 模型侧基准期究竟该用 1983-2012（论文观测口径外推、技术可行）还是同时段 XGHG 池（自洽但偏离）—— 需用户拍板。
- `binary_erosion` 边界伪边缘「放宽 1.0 门限后会不会伪配对」—— 当前门限下为 0，未测放宽情形。
- 海陆掩码未与 CAM landmask 交叉核对的误差量级。
- 观测侧 `coastal_pairs.csv` 的 0–360 经度列是否会污染未来消费者。
