audit(phase6): 归因管线正确性审计——发现并修复 2 个 P0 检测错误 + 3 个 P0 工程缺陷

动机
----
Phase 6（CESM1-LE GHG 归因，论文图3/图4）是论文最大的科学主张（FAR 0.95），
但至今只做过冒烟测试。本次在不下载、不跑全量的前提下，对 python/phase6_cesm.py
逐项核验其正确性（Lead + 3 名独立审计员四路并行，全部结论回到代码、真实数据与
本机 heatwaveR 0.5.5 实测，不采信任何文档自述）。

发现（详见 results/phase6审计报告.md）
-------------------------------------
P0-1 _pooled_threshold_t2m 的 axis 崩溃：11 天窗把 11×206 拼成 1 维，
     np.nanpercentile(axis=0) 退化为标量并广播 ⇒ 206 个陆点共用一条全欧阈值曲线。
     实测 thresh_t2m_xghg.npz 每一行行内极差恒为 0；阈值 mean|Δ|=8.26 °C，
     最冷点被抬高 18.49 °C。四方独立复现一致。
P0-2 _run_events 是「先桥接后过滤」，heatwaveR proto_event 是「先过滤后桥接」。
     450 例模糊测试 429/450 不一致（detection-auditor 独立跑 1350 例互证）；
     真实数据超阈天数被放大 1.77×。
P0-3 --members 20 静默只跑 3 个成员：MEMBERS_P0 已被 CESM_P0_MEMBERS=3 截断，
     MEMBERS_P0[:20] 仍只有 3 个元素 ⇒ 440 模型年永远拿不到。
P0-4 阈值缓存 thresh_*_xghg.npz 无成员名单指纹，只判文件是否存在，
     先跑 --members 3 再跑 --members 20 会静默复用旧阈值。
P0-5 不支持 leave-one-out（exclude_member 全项目 0 处），与 PHASE_B 步骤 2b 主口径不符。
高   模型侧 MHW 阈值缺 11 天窗（观测侧 heatwaveR windowHalfWidth=5），
     海陆口径不一致；v1 MHW 超标日放大 1.49×/1.53×。
中   ALL 组成品 T2m 时间轴在 12:00、POP SST 在 00:00 ⇒ _event_daily_mask 的
     .days 向下取整使 ALL 组 MHW 掩码整体早 1 天（XGHG 组不受影响），
     两组口径因此不可比：ALL 复合日 63154→62191 / 75581→74707 / 78973→78045。
高   bootstrap 静默丢弃 inf 重复（med_max 口径 372/1000），把 CI 系统性压低；
     报出的 "CI 14.7-53.0" 其实是 PR 的 CI，不是 FAR 的。
高   归因阈值用本复现自己的 2022 值（med_mean 20.7 / med_max 128），
     而非论文 Fig.3c 的 62/78/72。
中   论文模型 Methods（paper_text.txt:546）把复合日定义为 "MHW fully encompasses THW"，
     而 cmd_compound 用 L477 的逐日共超标口径。

已确认无误（用于界定影响面）
---------------------------
206 对逐行复现成功（POP 全球湿点 86212 → 唯一 f09 海格 1231；206 对/唯一陆点 206/
唯一海点 191）；键空间一致无静默错配（12 张事件表无越界）；_load_sst_points 块读
索引维度对齐（抽 24 点 max|块读−isel|=0）；坐标对齐无纬度翻转（探针 max|Δ|=0.0000 °C）；
K→°C 正确（TREFHT 两段 units='K' 都减了 273.15，SST units='degC' 无需换算）；
XGHG 两段拼接 8030 天无重复无缺口、接缝无不连续证据；FAR/PR 公式方向与论文 Eq.2/Eq.3 一致；
统计单元 66（20 成员时 440）符合论文"440 model years"。
**观测链路（Phase 1–4）全部走 R heatwaveR，不受影响。**

改了什么（全部在 python/phase6_cesm.py，F1–F8）
----------------------------------------------
F1 _run_events 逐行复刻 heatwaveR:::proto_event（含"吸收尾部空档、不吸收首部空档"
   的头尾不对称语义）
F2 _pooled_threshold_t2m 改为逐点独立求分位
F3 阈值分位统一为 ts2clm 语义：11 天窗内合并原始样本再取分位（SST 此前完全无窗）
F4 阈值缓存文件名带成员名单 + 版本指纹，读缓存时校验 n_members
F5 --members N 作用于全量 20 人名单，越界显式报错
F6 新增 --loo（leave-one-out），对齐 PHASE_B 步骤 2b 主口径
F7 bootstrap 不再丢弃 inf；0/0 → nan；用次序统计量求经验分位数（避免 inf−inf→nan）；
   输出 inf 比例与「保留 inf / 仅有限样本」两套 CI
F8 日期原点统一 .normalize()，消除 ALL 组 MHW 掩码早 1 天

如何验证
--------
1) proto_event 等价性（F1）：把事件逻辑与阈值解耦，自建带 thresh 列的气候态数据框直喂
   heatwaveR::detect_event；450 例（150 随机序列 × 3 组参数）——
   旧实现不一致 429/450，「先过滤后桥接」近似 5/450，新实现 0/450；
   detection-auditor 独立跑 9 组参数 1350 例同样 0 不一致；
   6 个手工边界用例（尾部空档 duration 7/6、首部空档 5、3超+2空+3超 → 无事件）全部相符。
2) T2m 阈值（F2/F3）：新旧阈值 mean 21.36 → 13.43 °C，mean|Δ|=8.26 °C；
   ALL 001 超阈率（南欧/北欧）12.8%/0.0% → 6.3%/6.5%。
3) 端到端前后对比（3 成员 P0，同一套代码、新旧 tag 并存，旧 _x 产物一个字未覆盖）：
   THW 事件 ALL 001 6468 → 18185、XGHG 001 3746 → 6042；
   THW 的 ALL/XGHG 事件比 1.73 → 3.01（强迫信号未被阈值缺陷掩盖）；
   复合暴露 ALL 001 63154 → 122282；22 年总暴露比 8.88 → 9.39；
   归因指标：med_max(128 天) 阈值下 PR 48.0 → ∞（修复后 P_fix=0，该数字作废）；
   可判读阈值下移到 med_mean(20.7 天)：PR=52.0、FAR=0.981（344/1000 inf，
   90% CI 含 inf 时上界为 inf、仅有限样本 [16.3, 57.0]）。
   ⇒ 方向性结论（GHG 强迫显著抬高复合热浪暴露、FAR 接近 1）不变且更强，
     但绝对数字全部作废，20 成员全量必须用修复后的代码跑。
   复算：results/phase6_audit_lead_check*.py / .R；
   日志 results/intermediate/audit/lead/fix_v3_{detect,compound,attrib}.log。
4) 回归基线：python python\verify_data.py → "All data files present and valid."
5) 文档同步：results/复现报告.md（新增 §0 审计结论、§5.1 第 8 行、§10 第 5 条、
   §11.6 加作废声明）、AGENTS.md（第四批条目 + 补登 CESM 侧配对口径 206/191/1.0≈112 km）、
