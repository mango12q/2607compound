## 诊断过程（三个关键实验）

### 1. marineHeatWaves 源码核验 —— 检测端无问题

抓取 [marineHeatWaves master 源码](https://raw.githubusercontent.com/ecjoliver/marineHeatWaves/master/marineHeatWaves.py)：
`detect()` 是**先过滤连续游程 ≥ minDuration(5)，再桥接间隙 ≤ maxGap(2)**
（`Find all MHW events of duration >= minDuration` → `Link heat waves ... across a short gap`）。

→ **heatwaveR 与 marineHeatWaves 语义完全一致**，当前 R 严格检测 = 论文工具口径 ✓
→ 旧的 Python 跨度口径（end−start≥5）反而与两个包都不同。

### 2. 平滑实验 —— 排除阈值平滑差异

论文用包默认参数，其中 `ts2clm(smoothPercentile=TRUE, smoothPercentileWidth=31)`（两包一致）；
我们此前为做归因实验显式关闭。抽样 90 个沿海对重测（`results/exp_smooth_compare.py`）：
Med 2022 复合天数 16.9→15.8，2023 32.5→32.9 —— **几乎无影响，假设否决**。

### 3. 复合定义对比 —— 根因所在

论文 Methods 有两个互相冲突的表述：
- **L477**："compound ... periods during which both T2m and SST **simultaneously exceed**
  their respective thresholds" → **逐日共超标**
- **L520**："a compound heatwave day = a day when a MHW **fully encompasses** a THW"
  → 整事件包含（containment，我们旧实现）

用同一套 R 严格事件对两种定义各算一遍（`results/diagnose_compound_definition.py`）：

| 论文锚点 | containment（旧图） | **共超标（新）** |
|---|---|---|
| 图1m 共现概率：地中海 0.6-0.8、西地中海>0.8 | ✗ 均值 0.34 | ✓ **p50=0.59, max=0.88** |
| 图2c CHR 2023=3.5 | ✗ 3.96 | ✓ **3.19**（地中海加权 3.61） |
| 图2b standalone 多数<10 天/年 | ✓ | ✓ **p50=7.4** |
| 图2a 若干区域>20 天/年 | ✗ p95=14.1 | ✓ **p95=22.3** |
| 图1j 天数 2022~78 / 2023~72 | ✗ 14/28 | ✗ 均值 20.7/37.9，格点最大 128/171 |

**共超标定义命中 4/5 锚点**，故采纳（`compound_events.py` 已重写为逐日共超标；
standalone 按日扣除，保证 C+S=全部 THW 日）。

## 第二轮排查（2025-09-18 下午）： Supplementary 与聚合空间穷举

- 论文补充材料（本地 `docs/附件材料-*.pdf`）仅 1 张图（S1 年际空间分布），**无任何方法文字**。
- 用户目视确认：论文 fig1j 曲线峰值在 **2022**（~78 天），2023=72，且全曲线 <90；
  面板为"一条折线 + 一条平滑趋势线"。
- 论文主文 L104/L114 定义主语是 MHW："measured as the total number of compound
  heatwave days per year"，"a marine heatwave fully encompasses a terrestrial heatwave"
  —— 支持"MHW 包络天数"（V1：某 MHW 完全涵盖 ≥1 个 THW → 计该 MHW 全部跨度天）。

### 结论与定稿（2025-09-18 用户确认）

论文 fig1j/l 的天数曲线配方无法从论文文本唯一确定（定义自相矛盾 + 峰值年份与
公开数据相悖）。图1 内部一致性要求 a-i 空间图与 j-l 曲线使用同一复合日数量——
**已定稿：主图维持共超标均值版**（与 fig1m/2a/2b/2c 四个锚点全部一致）；V1 包络版
（figS2_jkl_mhw_envelope.pdf）与 maxcell 版（figS1_jkl_maxcell.pdf）留作补充材料。
wMed-V1 76/68.5 的精确匹配作为对论文数值的最可能解释记录在案。
