## 怎么复现这张表里的每一行

```bat
:: 一次性全跑（缺数据自动跳过）
run_all_phases.bat

:: 或按阶段
python python\run_all.py                 :: Phase 0-3 → 图1/图2 的输入
python python\figures.py                 :: 图1 / 图2 / S1(j-l)
python python\fig_jkl_mhw_envelope.py    :: S2
python python\figS1_annual_maps.py       :: 论文版 S1
python python\phase5_humid.py all        :: 图5/图6 的输入（需 Phase 5 数据）
python python\fig5_sst_trend.py          :: 图5
python python\fig6_wbt.py                :: 图6
python python\phase6_cesm.py gev --members 20 --tag _v12w50 --mapping emp   :: 图4 的输入（主口径）
python python\fig3_attribution.py  --tag _v12w50                          :: 图3
python python\fig4_return_period.py --tag _v12w50                         :: 图4
python python\table1_attribution.py --tag _v12w50 --out results\tables\table1_v12w50.csv  :: Table 1
```

> ⚠️ Phase 6 的 `--tag` 必须与 `detect` 时一致，且**主口径 `_v12w50` 依赖**：
> `detect --baseline self --loo --clim-period 1983-2012 --thresh-offset-xghg-t2m 0.5645` + `gev --mapping emp`
> （见 `results/复现报告.md` §5 D7.7）。一条命令起全链：`logs\_run_v12w50.ps1`（≈5.7 min）。
> `_v4` 等更早的 tag 只是历史口径，别再用于交付图。

> 目视比对方法：把上表左栏的论文原图与右栏产物并排打开；
> 数值判据用「锚点」列的链接跳到 `results/复现报告.md` 对应小节。
